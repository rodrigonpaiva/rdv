## Packaging correction found during execution

The first exact archive-membership check found macOS AppleDouble `._*` files generated by tar but absent from the verified manifest. The payload hashes themselves were correct, but the archive contained additional metadata entries. This is corrected in the archive helper with `COPYFILE_DISABLE=1`, without changing payload bytes; GNU tar ignores that environment setting.

The real archive regression writes a synthetic xattr on macOS, packages the fixture, checks exact members and checks extracted bytes. It also runs on Linux without the platform-specific xattr step. Final quality and artifact checks were repeated after this correction; the final archive has only the manifest-listed payload and manifest.

This adds only a CI packaging helper/test to the existing source-copy, report-retention, architecture, build-cleanup and migration-CLI correction slice. No domain, API, dependency, OpenAPI or SQL migration changed.
